# 度量

**何时加载本参考：** 需要报告扫描分数、判断某次命中是不是误报，或与审阅者约定一条通过阈值时。

`scripts/scan.py` 是一台短语检查器。它按类别逐条匹配一份写死的、可复核的 tell 清单，并报告它们落在哪些行上。每条命中带两个标识：模式编号（`A1`）与类别 token（`not-just-x`）。它只做这一件事，它的数字也只意味着这一点。

## 扫描能证明什么，不能证明什么

| 扫描能证明 | 扫描不能证明 |
|---|---|
| 在当前提交上，这些确切的模式出现在这些行上。 | 文本是模型写的。人也能整天写 "it is important to note that"。 <!-- scan: ignore B4 这句话是引用的例子 --> |
| 两次运行之间，命中数在可比文本上下降了。 | 改写后的文字更好读。只有读者能判断。 |
| 没有漏掉源文档引用里的 tell —— 这份清单是确定性的。 | 剩下的文字是好的，或改写后的论断仍然成立。 |
| 某个类别不存在。 | 该类别意义上的句子不存在：多数 tell 都有变体，而词表里没有。 |

由此有两个结论。第一，绝不要把一次干净的扫描当成作者身份或质量的证据；它只能证明某个具体、可重跑的检查通过了。第二，一次命中是一个问题，不是一个判决 —— 由保留还是删除的判断表来决定，而且这个决定要记录下来。

## 单位与比率

分数行报告：

```
score: <distinct lines flagged> distinct lines flagged; <hits> occurrences; <units> units (<words> words + <cjk> CJK characters); rate <n> per 1000 units
```

- **命中行数**是首要数字：一个塞满限定词的句子无论触发多少个模式，只算一次行。阈值就设在这个数字上。
- **命中次数**统计每一次匹配，用来看剩下的命中是否聚在一起。
- **单位**是拉丁词 token 加上中文字符。中文没有两个工具都认同的空白分词方式，所以字符是唯一稳定的单位；一份文档里混排两种文字没有问题，两边各贡献一个单位。
- **比率**是每 1,000 个单位的命中次数。用它比较长度不同的文档，并且只在同一种语言配比内比较 —— 每 1,000 个英文词 10 次命中，与每 1,000 个中文字符 10 次命中，不是同一个密度。

围栏代码块既不扫描，也不计入单位。匹配前，扫描器先遮蔽行内代码（所以反引号里的 `not just X but Y` 不会触发），但行内代码仍计入单位，因为它属于一个散文句子。

## 分数怎么报告

要报告命令、输入文件，以及两次运行的结果。只有一个数字而没有基线，不叫度量。

```console
$ python3 scripts/scan.py draft.md; echo exit=$?
score: 9 distinct lines flagged; 21 occurrences; 612 units (410 words + 202 CJK characters); rate 34.3 per 1000 units
draft.md:4: B4 hedge-stacking: It is important to note that
...
exit=1

$ python3 scripts/scan.py draft.md; echo exit=$?
score: 1 distinct lines flagged; 1 occurrences; 648 units (430 words + 218 CJK characters); rate 1.5 per 1000 units
draft.md:57: A1 not-just-x: not just faster, but
exit=1
```

接受一条幸存的命中，需要一个理由，而不是一句含糊其辞：「第 57 行保留这个句式，因为这句话对比了新旧调度器，而对比正是这一段的论点。」把这个句子写进变更表的 `原因` 列。

## 误报类别

这些模式刻意收得很窄 —— 多词短语和封闭词表 —— 但仍有十一类误报存活，而这十一类都理应保留。

| 类别 | 例子 | 处理 |
|---|---|---|
| 引用文本 | 稿件把 "In today's fast-paced landscape" 当作反面例子引用 | 保留；在该行标 `scan: ignore C1 这是一处引用`，并说明这是引用。 |
| 代码与标识符 | 一个叫 `unlock_potential` 的函数，一行含 "leverage" 的日志 | 保留；这一行是数据。若与散文相邻，标 `scan: ignore C1 这一行是数据`。 |
| 合理的列举 | 在一篇库评测里写 "powerful, readable, and tested" | 判断：词表只收营销形容词，本来就不该命中；如果命中了，说清这三项各自差在哪。 |
| 承重的句式 | "It's not just a cache but a write buffer"，而这个对比正是设计决策 | 保留；把这个对比记为理由。 <!-- scan: ignore A1 这个句式是引用的例子 --> |
| 领域含义 | 金融文档里的 "leverage"，作为可测量轴的 "维度"，统计学的 "robust" | 保留；这个词带着它的技术义。 <!-- scan: ignore C1 C9 这些词是引用的例子 --> |
| 成语与文雅表达 | 「事半功倍」「未雨绸缪」「行云流水」 | 保留；地道的成语是正常修辞，不是 AI 词汇。 |
| 孤立的连接词 | 一段本来平淡的段落里出现一个「然而」或 "Moreover" | 保留；只有每段开头机械重复才是 tell。 |
| 必要的被动与规范句式 | 论文或规范里的「实验数据由传感器自动记录」 | 保留；这句话说清了谁在做什么。 |
| 必要的条目列表 | API 参数列表、会议待办 | 保留；对这些东西，列表就是最清楚的形态。 |
| 作者有意的排比 | 「他来了，他看见了，他做到了」 | 保留；这种重复是作者的修辞，不是口头禅。 |
| 同形状的形容词三元组 | 可靠、安全、灵活 / "reliable, secure, and flexible" | 判断；这个形状在两种语言里都会触发，按保留还是删除的判断表决定，别凭反射。 <!-- scan: ignore B1 这个三元组是引用的例子 --> |

豁免是按行、按类别生效的。标记要写出类别 token 或模式编号，并带上理由：

```markdown
The old copy read "unlock the power of your data". <!-- scan: ignore C1 the quote is the bad example -->
```

`scan: ignore translated-diction the quote is the bad example` 与
`scan: ignore C1 the quote is the bad example` 豁免的是同一条命中：标记接受类别 token（`translated-diction`）或模式编号（`C1`），v2 之前写的标记继续有效。绝不整篇文件加一个笼统的忽略，也绝不为一个类别在整个文档上豁免：文档级豁免会让这道闸门变成空转，把回归藏到它后面。

## 没有探测器的模式

扫描器只自动化那些字面固定的措辞 —— 它不必读上下文就能匹配的短语与封闭词表。有三项判断留给读者。

- **B10 —— 句长齐一。** 一段里每个句子的长度都落在彼此相差几个词的范围内。判据：把这段读出声；如果读起来像节拍器，就把长度错开。
- **F1 —— 重复读者已知。** 一条回复把问题重述一遍，走一遍诊断，把证据摊开，然后才给结论。判据：只在读者上下文可见时才动手 —— 或者周围对话可见，或者这条回复明显接在一条对话之后。
- **B、C、D 三组标着 *weak alone*。** 这三组里的任何一次命中都需要同伴：同一段文字里还有别的 tell，才值得动手。A 组（铺陈代替陈述）与 E 组（聊天与草稿残留）看到一次就可以改；B 组（按规则套节奏）、C 组（膨胀与借来的权威）、D 组（按规则套格式）不行。

## 通过阈值

| 场景 | 阈值 |
|---|---|
| 新写的文字，发布之前 | 0 处命中。任何命中要么改写，要么给出明确理由。 |
| 改写一份已有文档 | 最终命中行数 ≤ 基线的三分之一，且同一类别每节重复不超过两次。 |
| 内部文档，长期维护 | 命中 ≤ 1 次 / 1,000 单位；任一类别 ≤ 0.3 次 / 1,000 单位。 |
| 不是你写的、且不能编辑的文档 | 报告分数和排名前三的类别；未经所有者同意不要改写。 |

阈值针对的是文档，不是作者。一份分数很高又不能改动的法律声明，是一份报告，不是一次失败。

## 验收规则

**命中下降，且论断没有改变。** 两半都要满足：

1. 最终扫描的命中行数少于基线，并且附上命令输出。
2. 改写里的每个数字、日期、标识符、专有名词与情态限定词，都以同样的含义出现在原文里。机械地比对 —— 把两个版本的数字 token 排序后对比；限定词手工读。
3. 每条幸存的命中在日志里都有一个理由，每一次改写都记录了精度是否保留。

日志的 `类别` 列同时写模式编号与类别 token，例如 `A1 not-just-x`。

分数下降却丢了数字，就没过第二项检验。删掉一个承载着唯一一处未测上限说明的限定词，是最常见的出错方式；改写手册里的精度规则就是为了拦住这件事。
